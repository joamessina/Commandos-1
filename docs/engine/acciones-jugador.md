# Acciones del jugador, habilidades, objetos y vehículos (ClassAU*, mochila)

Estado: **PARCIAL, en ampliación**. Marcas: **[hecho]** = leído en el exe/datos con dirección; **[hip]** = hipótesis; **NO LEÍDO**.
Método: `RTTI -> vtable -> función` (las entradas de vtable son stubs `jmp`; el decompilado del stub muestra el cuerpo real). Direcciones = stub (vtable) y entre paréntesis la función real. Constantes `_DAT_` = double, `DAT_` en argumento float = float (leído del PE).

## 1. Resumen ejecutivo
- **Quién puede qué** no está en el código sino en los **datos**: cada comando es un `.CLASS BICHOALIADO` en `.ELEMENTOS` de cada `MAPAnnnn.MIS`/`TUTnn.MIS`, con su lista `.ACCIONES [ [ AuXxx [ .CARISMA 200 .param … ] ] … ]` (§3). **[hecho]**
- Las acciones de usuario `ClassAU*` se activan por **mensajes de clic** (`MSGA_ACTUASOBREELEMENTO[DBLCLK]`, `MSGA_ACTUASOBREPUNTO[DBLCLK]`) y por la **mochila/barra de ítems** (§5), que guarda por ítem el id de acción. **[hecho]**
- El objeto clicado responde con un mensaje `MSG_SOY_xxx` y el aliado elige la acción (§4). **[hecho]** `0x515A30`.
- Ritmo: 20 ciclos/s (ver `exe-lectura.md`); todas las duraciones de abajo están en **ciclos de lógica** (ticks), salvo que diga otra cosa.

## 2. Esqueleto común de una acción AU
Jerarquía (RTTI): `ClassAccion` <- `ClassAcUsuario` <- `ClassAcUsuarioGoto` <- `ClassAU*` (las "Goto": caminan hasta el blanco; 28 slots de vtable). Sin Goto (21 slots): `AUAgacharse, AUCamuflarse, AUDisfraz, AUDisparar, AULanzallamas, AUManejaBomba/Cepo/Item/Segnuelo, AUQuietorrr, AUTabaco`. `AuBucear` y las demás ver slots. **[hecho]**
Slots usados (índice de vtable): 1 = lee parámetros del MAC/MIS (`.FLAGSUSAR`, `.ARMAS`…), 4 = **tick**, 5 = **manejador de mensajes**, 8/9 = guardar/cargar (`0x409200/0x406235`), 13 = activar (con parámetro), 14 = desactivar, 17 = `getBicho()` (devuelve `this+0x1C`).
Campos de la acción (this = param_1, índices int): `[7]` bicho dueño; `[0x62]` **estado** de las Goto (0 inactivo, 1 esperando, 2 caminando al punto, 3 caminando al elemento, 4/5 actuando, 7 enfriando); `[0x67..0x69]`/`[0x68..0x6A]` blanco = puntero + lista de enlaces (se desenlaza al soltar); `[6]`/`[99]` contador de ticks de la animación. Las no-Goto usan `[10]` como estado. **[hecho]**
Patrón de ejecución típico (Acuchillar `0x4E5C50`, Esposas, Coger, Usar): caminar -> **chequeo de alcance** `FUN_0050A380(blanco)`: distancia desde el bicho al blanco (ajustada por radio) `<= bicho+0x180` **y** ángulo `|dif| < 15` (double `0x795658`) -> orientar (`MSGO_MOTOR_SETANG`; se espera hasta **±5** `_DAT_00795F50` grados o **3 ticks**) -> reproducir animación con `FUN_00515400(bicho, nombre, velocidad, modo, flag)` (guarda nombre en `bicho+0x8A8`, contador de cuadros `bicho+0x8CC` a 0) -> a un cuadro fijo aplica el efecto -> al terminar el nº de cuadros (`bicho+0x8CC` = duración) libera y vuelve a idle `FUN_004E54A0`. **[hecho]**
Efectos hacia otros: `FUN_005986a0(bicho, blanco, tipo, valor)` envía `MSGA_IMPACTO` con `{tipo, pos, valor}`; `FUN_005fe570(-1, destino, msg, a, b)` envía mensaje genérico. Voces: `FUN_00513c70(n)` (el comando dice una frase; n=7 respuesta/arranque, 3, 2…) **[hecho]**, texto de cada n **NO LEÍDO**. Sonidos de objeto: `FUN_0067F9C0('XXXX', pos, 0.75f)` con código de 4 letras (multichar C++: `'CACH'`, `'ESPO'`, `'ENTE'`, `'CBAR'`, `'CEPO'`, `'SOLD'`, `'SCUE'`, `'GRAN'`); volumen 0.75 (`0x793240`). Estos son **sonidos**, no "ruido para IA" (eso queda a percepción). **[hecho]**
Banderas de bicho (`bicho+0x23C`): `0x04` = muerto/inactivo (no actuable), `0x40` = agachado (altura `+0x58 = +0x7C8 * 0.125`, double `0x79A3E0`), `0x80` = agachándose/bajo, `0x1000|0x80000` = buceando, `0x8000` = lleva cuerpo (Garfio), `0x8000000` = "elemento móvil con punto propio". `bicho+0x824`: `0x8000` arma desenfundada, `0x400` lleva muerto, `0x10` en habitáculo. **[hecho]** (semántica fina: [hip])
**Índice de personaje** `bicho+0x7A8` = `FUN_0056EB70(nombre)` sobre tabla `0x8185C8`: `0 COMANDO, 1 FRANCOT, 2 LANCHERO, 3 ARTIFIC, 4 CONDUC, 5 ESPIA, 6 CHICA, 7 FUSILADO, 8 ALEMAN_CONTROLADO`. **[hecho]**
Máscaras de capacidad del bicho: `+0x7B0` = qué categorías **recoge** (Coger); `+0x7B4` = qué **usa**/capacidades (`1` escalar muros; `0x100/0x200/0x400` usar cajas de granadas/metralleta/balas de francotirador; `2/4/0x10` tipos de vehículo). **[hecho]**

## 5. Mochila / barra de ítems **[hecho]** (estructura), semántica de algunos campos [hip]
- Cada aliado tiene un `SUBINTERFACEALIADO [ .TOKEN <aliado> .CARETO CARAnnnn.RLE .ITEMS [ [ .TOKEN IT_x (.DISPONIBLE NO) ] … ] ]` en el `.INTERFACE .SUBINTERFACES` de cada MIS, más `SUBINTERFACEMULTIPLE [ .TOKEN MULTIPLE .ELEMUSABLES [ ZODIAC5 ALBERGUE02 ESCALA01 ASCENSOR … ] ]` (elementos del mapa que se pueden usar con selección múltiple) y `.INFOCARAS [ CARA [ .TOKEN X .ACCESIBLE 1 ] ]`. Ejemplo m00: COMANDO = PISTOLA, CUCHILLO, MANO, SEGNUELO, ACTSENUELOOFF/ON (no disponibles al inicio), PIEDRA, ESPOSAS, TABACO (NO), CONTROLALEMAN, INTERRUPTOR_ASCENSOR, GOLPEAR. LANCHERO = CUCHILLO, PISTOLA, BALSA(NO), MANO, TRAJEBUZO, ARPON, PIEDRA, TABACO(NO)…; FRANCOT = MANO, PISTOLA, MIRILLA, BOTIQUIN, PIEDRA…; ARTIFIC = MANO, PISTOLA, CEPO, CARTUCHO, ACTIVADOR, PIEDRA….
- **Ítem = struct de 0xAC bytes** (`FUN_00684840`, parser; 0xAC = `FUN_00689050`/`0068E770`). Campos (offset): `+0x20` id de ítem (por `TOKEN`, `FUN_0069F420`), `+0x24` IDTOOLTIP (4 letras, ej. `PIST`), `+0x2C` DISPONIBLE, `+0x30` VISIBLE, `+0x34` (clave vacía; SI), `+0x38` MOCHILA (SI = va a la mochila), `+0x3C` BITDESACTIVA, `+0x40` ILUMINAITEM, `+0x44` MIRASIDISPONIBLE, `+0x48` **ACCION = id de acción AU** (§6), `+0x4C` CMAPA, `+0x50` **PARAM** (cadena que se pasa a la acción: `PISTOLA`, `SUELTA`, `LETAL`, `COGE`…), `+0x70` IDGRUPO, `+0x74` BEMPIEZAACTIVA, `+0x78/+0x7C` dos índices (cursor/icono: pistola 0x1C/0x1D; mirilla 0x18/0x19; cuchillo 2/1; mano 0x17/0x16 …), `+0x88` BRECIBEBOTON2, `+0x8C` BACEPTACLICKSALIADOS, `+0x90` BPERMITIDOENVEHICULOS, `+0x98` BMULTIPLEPERMITIDO, `+0x9C` BMULTIPLESOLOCLICKSGOTO. Tabla estática construida en `FUN_00786E60` (global init).
- Cada sub-interfaz define 3 "sintaxis" de clic: `AuActiva` (ítem seleccionado), `AuUsar` (sobre elemento), `AuGoto` (sobre suelo) (`TSINTAXACTIVA/PTSINTAXACTIVA/PTSINTAXSELECCIONADA`; offsets `+0x14B8/+0x1564/+0x140C` del subinterface). Cambio de ítem = cambiar la sintaxis activa y llamar `activar` de la AU asociada. Detalle del HUD: NO LEÍDO.
- Estado guardado de la mochila: `.MOCHILA %s .ESTADO %ld .ACTUALILUMINADO %ld .BMOSTRARBOLSO`; mensajes `MSG_RESTAURA_ITEMS_MOCHILA, MSG_ACTUAITEMMOCHILA, MSG_INTERCAMBIO_ITEM, MSG_ITEM_ACTIVADO, RECOGEMOCHILATIPO`. `acMochilaAliado` (CMochilaAliado) y `D_ED_TOKENMOCHILA` ("Acción asociada, Parámetro, Grupo" = campos `ACCION`, `PARAM`, `IDGRUPO` de arriba). `FUN_00513210(id)` = quitar ítem de la mochila (virtual `+0x74` del subinterface en `bicho+0x834`).

## 7. Acciones, una por una (tick = ciclo)
### Pelea / daño
- **AUAcuchillar** (`0x401F0A` -> `FUN_004E5C50`, 315 B) **[hecho]**: Goto al enemigo (estado 3); al llegar (`FUN_0050A380`) y si no está muerto: mira al blanco, anim `SACACUCHILLO` (vel 1.0, modo 6), estado 5 con contador; **en el tick 6 envía `MSGA_IMPACTO` tipo 7, valor 0x78 (120)** al blanco (`FUN_004E5B00`); termina al agotar los cuadros de la animación. Habilita: Boina Verde y Marino. Sin ruido de objeto propio en el tick. Desactivar `0x40D797` (`MSGA_ARMA_ENFUNDADA`).
- **AUCachiporra** (`0x41166C` -> `FUN_004EAFD0`) **[hecho]**: igual que cuchillo (impacto en tick 6, `FUN_004EADF0`), anim según **índice de personaje**: `0` COMANDO -> `LANZARPIEDRA` [hip: reutiliza la anim], `4` CONDUC -> `SACACACHIPORRA`, `5` ESPIA -> `JERINGA` (vel `_DAT_00795740`), otro -> `ANDAR`. Slot 1 `0x4100F5`: si el token del bicho **no** es `ESPIA` pone `this+0x198=1` y precarga el sonido `'CACH'` que suena en el tick 6; el espía es silencioso **[hecho]**. Items: CACHIPORRA/CLOROFORMO/GOLPEAR (param distingue) — valor de impacto por ítem **NO LEÍDO** (`FUN_004EADF0`).
- **AUJeringuilla** (`0x405AB0`) **[hecho]**: Goto -> anim `JERINGA` forzada a **12 cuadros**; en el cuadro 10 envía `MSGA_IMPACTO` tipo **9**, valor 0 (`FUN_004F7E00`); parámetros `.TIPOJERINGA LETAL .DOSIS 5`.
- **AUBotiquin** (`0x407347` -> `FUN_004E90E0`) **[hecho]**: solo sobre aliado (`vtbl+8 == 2`) con energía actual `<` máxima (`+0x208 < +0x20C`); anim `JERINGA` vel 1.0; en el cuadro 10 **cura +0x22 (34)** (tope = máx.) y descuenta uso (`.USOS`, 5); al llegar a 0 usos quita el ítem `0x52`. ## 8. Vehículos (parcial)
- Quién maneja: el bicho que entra al habitáculo (`AuUsarVehiculo` o `AcUsaHab`) queda en `bicho+0x134`; el vehículo es un `CBicho` con `acPilotaje` + motor `MotorVehiculo{Auto,Balsa,Ciclo,Lancha,Sub,Tanque}`; recibe `PILOTO_GOTOVEL/PARAR`. **[hecho]**

## 9. Hallazgos para otros
- **Armas/daño**: impactos enviados por el jugador son `MSGA_IMPACTO {tipo, pos, valor}` (`FUN_005986A0`): cuchillo tipo 7 valor 120; jeringa tipo 9 valor 0; cepo tipo 14 valor 1; tabla de armas §6.2 y recarga +0x2C. Receptor: `ReceptorImpactosDef 0x45F2F0`.
- **IA/mensajes**: lista `MSG_SOY_*`, `MSGA_HAS_SIDO_ESPOSADO`, `MSGA_ME_HAS_ESPOSADO`, `MSGA_HAS_SIDO_DETENIDO`, `MSGA_PUEDO_IR_A_COGERTE`, `MSGA_ESTOY_YENDO_A_COGERTE`, `MSGA_NO_VENGAS`, `MSG_SEGNUELO_ONOFF`, `MSG_MANIPULA_BOMBA`, `MSGA_ERES_EMPUJADO`.
- **Sonido**: sonidos por código de 4 letras `FUN_0067F9C0('XXXX', pos, 0.75)` -> `FUN_0067F490`: `CACH, ESPO, ENTE, CBAR, CEPO, SOLD, SCUE, GRAN, DISPAROPISTOLA/METRALLETA`; voces `FUN_00513C70(n)`.
- **Movimiento/colisión**: altura agachado/buceando = altura * 0.125 (double `0x79A3E0`); `bicho+0x180` = alcance de interacción, `+0x7C8` altura de pie.
- **Percepción**: apariencia del espía `bicho+0x108` (1 alemán, 2 aliado); disfrazado = `0x23C&0x800000`; agachado `0x23C&0x40`; buceando `0x1000|0x80000`; camuflado `bicho+0x230=1` (AUCamuflarse).

## 9b. Datos de objetos de caja (AcRecogeArma `0x40E322` / AcRecarga `0x40A871`) **[hecho]**
Parámetros: `NUMARMAS` (`+0x19C`), `TOKENARMA` (`+0x1A0`), `BALASINICIALES`/`BALASRECARGA`, `FLAGSRECOGER`, `TOLTIP_LLENO/VACIO`. `FL_GRANADAS`: marca la caja con `+0x250 |= 8` (categoría de AUCoger) y `+0x254 |= 0x100` (categoría de AUUsar); `FL_METRALLETA`: `0x10`/`0x200`; `FL_BALASFRANCOT`: `0x20`/`0x400`.
